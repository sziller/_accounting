Accounting software for private bookkeeping purposes.

The root repository is hosted on GitHub, and the software is developed as an open-source project.

User accounting data, invoices, receipts, database files, and other private records should be stored separately from the public source repository, preferably in a private repository or other suitably protected storage.

The repository may include example data intended for tests, tutorials, demonstrations, and rehearsal use. Such example data should not contain real private accounting information.
